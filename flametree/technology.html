Technology

Engineered from first principles, accelerated on GPU

Flametree calculates every metric from first principles, then runs the heavy lifting on GPU. The result is an attribution engine typically orders of magnitude faster than comparable systems.

01 · Architecture

Data-light architecture

Flametree calculates every metric from first principles, using security master data and a yield curve alone. Returns, modified duration, convexity, YTM, OAS and a broad set of further quantities are produced as a natural extension of attribution analysis.

02 · Modularity

Microservices

Flametree is built on a microservices architecture: modular, loosely coupled components that are independently deployable, each with clearly defined interfaces following industry standards. Components communicate through open, documented APIs, enabling clients to define and use their own pricing models alongside those in our standard library.

03 · Performance

High speed computation

Fixed income attribution is computationally demanding, requiring every security in both portfolio and benchmark to be repriced multiple times per valuation date. Flametree avoids conventional database architecture and is not subject to typical hardware bottlenecks. Computation is GPU-accelerated, delivering an attribution engine that is typically orders of magnitude faster than comparable systems.
